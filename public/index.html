Liveblocks MCP Server

Connect your AI app to a Liveblocks project to inspect rooms, read Storage, and work with threads and comments.

Add this URL as a remote MCP server in your app:

https://mcp.liveblocks.io/mcp

Sign in with Liveblocks, choose a project, then select Allow access. Read only is selected by default. If your app requests write access, you can choose Read and write.

Already using a project secret key? Your existing bearer token configuration works with the same URL.
