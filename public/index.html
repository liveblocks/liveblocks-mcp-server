Liveblocks MCP Server

This is a hosted Model Context Protocol server for the Liveblocks REST API. It uses the Streamable HTTP transport and is served at /mcp.

Authenticate with your Liveblocks secret key from the dashboard, sent as a bearer token: 

{
  "mcpServers": {
    "liveblocks": {
      "url": "https://mcp.liveblocks.io/mcp",
      "headers": {
        "Authorization": "Bearer sk_xxxxxxxxxxxx"
      }
    }
  }
}
